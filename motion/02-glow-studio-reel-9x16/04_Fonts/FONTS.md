# Fonts

Install before running the script (free, Google Fonts):

- Montserrat (ExtraBold, Medium) — https://fonts.google.com/specimen/Montserrat
- Playfair Display (Italic) — https://fonts.google.com/specimen/Playfair+Display

If a font is missing, the script still works and uses After Effects' default font — just install the fonts and re-run it.
