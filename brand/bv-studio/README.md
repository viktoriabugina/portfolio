# BV Studio by Victoria — Brand Identity

![Brand board](bv-studio-brand-board.jpg)

Monoline monogram: a lowercase **b** and a peach **v** share one stroke weight and overlap into a ligature. Rounded caps keep it friendly; the dark/cream/peach palette matches the portfolio site.

| `bv-mark-dark.svg` | Mark for light backgrounds |
