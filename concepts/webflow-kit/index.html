Site structure demo

Clean layout, ready for your content.

A responsive structure with the two features you asked for: an autoplay, partial-view, infinitely looping photo slider and syntax-highlighted code blocks. Everything is built with classes you can restyle in the Webflow Designer.

Code blocks

Source code that reads well.

Each block shows the language and has a Copy button. Highlighting is done by Prism.js, loaded once in the site settings, so any code you paste into a Webflow Code Embed is coloured automatically.

How it is set up in Webflow

  • Slider: a Collection List (or static images) with a small custom script for the infinite loop and autoplay.
  • Code blocks: an Embed element with a pre and code tag; Prism styles it.
  • All sizes use rem and percentages, tested on desktop and mobile breakpoints.
slider.js
// Infinite autoplay with partial view of the next and previous slides
const track = document.querySelector('.slider__track');
const slides = [...track.children];
let index = 0;

function goTo(i) {
  index = (i + slides.length) % slides.length;
  const offset = slides[index].offsetLeft - (track.parentElement.clientWidth - slides[index].clientWidth) / 2;
  track.style.transform = `translateX(${-offset}px)`;
  slides.forEach((s, n) => s.classList.toggle('is-active', n === index));
}

setInterval(() => goTo(index + 1), 4000);

def fibonacci(n: int) -> list[int]:
    """Return the first n Fibonacci numbers."""
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]
