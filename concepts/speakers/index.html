Below is how the section would work on your site: it drifts on its own, pauses when someone hovers or taps, can be dragged or swiped, and has arrow buttons. Underneath: how you add a new speaker in Squarespace, and the small code that makes it move.

Adding a new speaker takes about a minute

  1. Open the section

    In the Squarespace editor, click the speakers section and choose Edit content. It is a built-in List section set to the Carousel layout.

  2. Add an item

    Click Add item, upload the photo, type the name, title and topic. Drag items to change the order.

  3. Save

    Press Save. The new speaker joins the moving carousel automatically, no code to touch.

The movement comes from one small snippet added once in Settings → Advanced → Code Injection. It works with the built-in carousel, so your updates never break it.

<!-- Speakers carousel: smooth auto-scroll for a Squarespace 7.1 List section (Carousel) -->
<style>
  .user-items-list-carousel__slideshow-holder { overflow: hidden; }
  .user-items-list-carousel__slides { transition: none !important; }
</style>
<script>
document.addEventListener('DOMContentLoaded', () => {
  // Pick the carousel inside the section with the "Speakers" anchor
  const section = document.querySelector('#speakers');
  const track = section && section.querySelector('.user-items-list-carousel__slides');
  if (!track || matchMedia('(prefers-reduced-motion: reduce)').matches) return;

  // Duplicate the slides once so the loop is seamless
  track.append(...[...track.children].map(slide => {
    const copy = slide.cloneNode(true);
    copy.setAttribute('aria-hidden', 'true');
    return copy;
  }));

  let x = 0, paused = false;
  const speed = 0.4; // pixels per frame
  section.addEventListener('mouseenter', () => paused = true);
  section.addEventListener('mouseleave', () => paused = false);
  section.addEventListener('focusin', () => paused = true);
  section.addEventListener('focusout', () => paused = false);

  (function frame() {
    if (!paused) {
      x -= speed;
      if (-x >= track.scrollWidth / 2) x = 0;
      track.style.transform = `translateX(${x}px)`;
    }
    requestAnimationFrame(frame);
  })();
});
</script>
