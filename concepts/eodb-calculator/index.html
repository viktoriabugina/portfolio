Where would your economy rank?

Answer four questions and get an instant estimate of your Ease of Doing Business rank.

  • Works inside a ClickFunnels HTML/JS element, no apps or backend
  • Responsive down to 320px wide phones
  • Dark blue, white and coral to match the funnel

Ease of Doing Business rank estimator

Four inputs, one estimate. A lower rank means doing business is easier.

  <script>
  (function () {
    var root = document.getElementById('eodbc');
    if (!root || root.getAttribute('data-ready')) return;
    root.setAttribute('data-ready', '1');

    var form = root.querySelector('.eodbc-form');
    var out = root.querySelector('.eodbc-out');

    // Typical rankings cover 190 economies; split into thirds.
    var STRONG_MAX = 63, AVERAGE_MAX = 127;
    var BANDS = {
      strong:  ['Strong', 'In the top third of typical EODB rankings.'],
      average: ['Average', 'In the middle third of typical EODB rankings.'],
      weak:    ['Weak', 'In the bottom third of typical EODB rankings.']
    };

    function field(id, label, min, max) {
      var el = root.querySelector('#' + id), err = root.querySelector('#' + id + '-e');
      var raw = String(el.value).trim(), v = Number(raw), msg = '';
      if (raw === '' || isNaN(v)) msg = 'Enter ' + label + '.';
      else if (v < min) msg = 'The value can’t be below ' + min + '.';
      else if (max !== null && v > max) msg = 'The value can’t be above ' + max + '.';
      err.textContent = msg;
      el.setAttribute('aria-invalid', msg ? 'true' : 'false');
      if (msg) el.setAttribute('aria-describedby', id + '-e'); else el.removeAttribute('aria-describedby');
      return msg ? null : { v: v, el: el };
    }

    form.addEventListener('submit', function (e) {
      e.preventDefault();
      var inc  = field('eodbc-inc',  'an income group', 1, 4);
      var days = field('eodbc-days', 'the number of days', 0, null);
      var bank = field('eodbc-bank', 'a percentage', 0, 100);
      var outg = field('eodbc-out',  'a percentage', 0, 100);
      var bad = [inc, days, bank, outg].indexOf(null);
      if (bad !== -1) { out.hidden = true; root.querySelectorAll('[aria-invalid="true"]')[0].focus(); return; }

      // Predicted rank = 35.187 + 11.284*Income − 0.676*Bank% + 1.593*Outage% + 0.181*PermitDays
      var rank = 35.187 + 11.284 * inc.v - 0.676 * bank.v + 1.593 * outg.v + 0.181 * days.v;
      rank = Math.round(rank * 1000) / 1000;

      var band = rank <= STRONG_MAX ? 'strong' : rank <= AVERAGE_MAX ? 'average' : 'weak';
      out.querySelector('.eodbc-rank').textContent = String(rank);
      var b = out.querySelector('.eodbc-band');
      b.textContent = BANDS[band][0] + ' estimate';
      b.setAttribute('data-band', band);
      out.querySelector('.eodbc-txt').textContent = BANDS[band][1] +
        (rank < 1 ? ' The model puts these inputs above the #1 spot, so read it as a top rank.' : '');
      out.hidden = false;
    });
  })();
  </script>

Pasting it into ClickFunnels

Takes about two minutes.

  1. Open the funnel stepEdit the landing page in the ClickFunnels editor.
  2. Add a Custom JS/HTML elementIn ClickFunnels 2.0 it's the "Code" element. Drop it where the calculator should appear.
  3. Paste the whole blockOpen the element's code editor, paste everything you copied above and save.
  4. Publish and test on the live pageScripts don't always run inside the editor, so check the published or preview URL, on a phone too.

Built around the element's limits

What I took care of so it behaves inside a page builder.

  • No external files. Nothing to host, no CDN, no fonts to load. It inherits the funnel's font.
  • Scoped styles. Every rule starts with .eodbc, so funnel styles stay as they are.
  • Safe script. Wrapped in a function and guarded, so it runs once even if the editor re-renders the element.
  • Input checks. Empty or out-of-range values get a clear message under the field instead of a wrong result.
  • Labeled as an estimate. The note credits Ina Ortiz (2014) and says it isn't an official World Bank score.
